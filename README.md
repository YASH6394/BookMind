# BookMind - PDF Question Answering

Ask questions about a PDF and explore the relevant passages in a clean, interactive chat interface. BookMind is a small Python project built with FastAPI; it automatically indexes the included *Wuthering Heights* PDF.

## Features

- Responsive chat interface with suggested questions
- PDF upload and indexing from the browser
- Page-numbered source passages for answers
- Local TF-IDF-style keyword retrieval
- No external LLM, API key, or vector database required
- FastAPI endpoints for health checks, PDF uploads, and questions

## Quick start

You need Python 3.10 or later.

```powershell
git clone https://github.com/YASH6394/BookMind.git
cd BookMind
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirement.txt
py -m uvicorn app:app --reload
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser. The included PDF is indexed automatically when the app starts.

To run the tests:

```powershell
py -m pytest -q
```

## Using the app

1. Enter a question or choose one of the suggested prompts.
2. Read the response and click a page citation to expand its source passage.
3. Use **Upload another PDF** in the sidebar to index a different document.

Uploading a PDF replaces the current in-memory index. Restarting the app loads the included PDF again.

## API

### Check index status

```http
GET /health
```

Example response:

```json
{
  "status": "ok",
  "indexed_chunks": 120
}
```

### Ask a question

```http
POST /query
Content-Type: application/json
```

Request:

```json
{
  "question": "Who is Heathcliff?",
  "top_k": 5
}
```

The response contains an answer and relevant source passages with page numbers.

### Upload a PDF

```http
POST /index/upload
Content-Type: multipart/form-data
```

Send the PDF in a form field named `file`. Only PDFs with extractable text are supported.

Interactive API documentation is available at [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

## How it works

1. **Extract:** `pypdf` reads text from each PDF page.
2. **Chunk:** Text is split into overlapping word chunks while preserving page numbers.
3. **Retrieve:** A local TF-IDF-style cosine similarity search ranks chunks against the question.
4. **Answer:** Relevant sentences are selected from the retrieved passages and returned with citations.

This project does not call an external AI service. Answers are selected from the document text, rather than generated by an LLM.

## Limitations

- Scanned/image-only PDFs need OCR before they can be searched.
- Search is keyword based, so it may miss passages that use different wording.
- The index is held in memory and is not preserved after restarting the app.
- The app indexes one document at a time.
